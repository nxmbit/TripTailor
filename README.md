# TripTailor

TripTailor is an AI-driven cross-platform (web and Android) travel planning app that automatically creates complete multi day itineraires given a date range, destination and attractions that you know you want to see there.

## Tech Stack
<b>Frontend (mobile and web)</b>: Flutter

<b>Backend</b>: Java, Spring Boot, Spring AI, OpenAI API, AWS S3, Google Places API, Firebase (for push notifications to mobile clients)

## Try It Out

<b>Web App</b>: [TripTailor](https://triptailor.nxmph.top/)

<b>Android App</b>: Download the latest APK from [Releases](https://github.com/nxmbit/TripTailor/releases).
